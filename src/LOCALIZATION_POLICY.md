# Localization Policy

## Default Language

英語をデフォルト言語とする。これは次の両方を含む。

- **フォールバック**: 明示のユーザー設定もシステム言語との一致もない場合は英語にする。対応外の言語・文字体系（繁体字など）も英語にフォールバックする
- **開発言語**: 文言のソース言語（Xcode の development region、String Catalog の source language 等）は英語にする。他言語は英語からの翻訳とする

## Supported Languages

アプリ内で選択可能な言語と、ロケール識別子・表示名は次のとおり。

表示名は各言語自身の表記（endonym）を使い、地域による注釈は付けない（例外は中国語、[Regional Variants](#regional-variants) を参照）。

| 言語 | ロケール識別子 | 表示名 |
|---|---|---|
| システム設定 | `system` | （各言語に翻訳） |
| 日本語 | `ja` | 日本語 |
| 英語 | `en` | English |
| 中国語（簡体字） | `zh-Hans` | 简体中文 |
| ヒンディー語 | `hi` | हिन्दी |
| スペイン語 | `es` | Español |
| フランス語 | `fr` | Français |
| ポルトガル語 | `pt` | Português |

## Regional Variants

地域によるロケールの書き分けはしない（例: 英語は米英を区別せず `en`、スペイン語はスペインと中南米を区別せず `es`、ポルトガル語はポルトガルとブラジルを区別せず `pt`）。

唯一の例外は中国語で、簡体字と繁体字は文字体系（script）が異なり相互に読めないため、`zh-Hans` のように文字体系まで指定する。現時点で対応するのは簡体字のみとし、繁体字対応が必要になったら `zh-Hant` を新たな対応言語として追加する（`zh` のように文字体系を省略して両方に一致させることはしない）。

ポルトガル語の文言はブラジル・ポルトガル語で書く（話者数が多いため）。ポルトガル本国のユーザーもシステム言語 `pt-PT` の言語コード部分（`pt`）で一致するため、別表記は用意しない。

## Language Resolution

言語決定の優先順位:

1. ユーザー設定
2. システム言語設定
3. 英語

システム言語設定との一致判定は言語コード（例: `pt`, `es`, `fr`）で行う。中国語のみ、言語コードと文字体系の両方（`zh-Hans`）が一致する場合に限り一致とし、文字体系が異なる場合（繁体字環境など）は対応外として英語にフォールバックする。

判定ロジック・保存方法・UI への反映など、実装の詳細は言語・フレームワークごとのトピックドキュメントを参照する。
